# Проверка экранов CLI

Проверка выполняется в настоящем PTY на macOS с Node.js 24.21.0. Для каждого сценария создаются отдельные временные настройки, рабочая папка и сервис. Запросы модели обрабатывает управляемый локальный провайдер; пользовательские задачи, ключи и аккаунты не используются.

Это карта маршрутов, а не попытка считать количество утверждений полным покрытием. Интерактивные страницы проверяются по текущему видимому кадру. Однократные отчёты команд проверяются по выводу терминала и коду завершения: они рассчитаны на обычную прокрутку терминала.

Дополнительный маршрут «Предел шагов» в настройках и «Предел шагов задачи» в действиях проверяется сценарием `playtest-iterations.py`: справка, ввод, подтверждение, сохранение, перезапуск и изменение состояния другим клиентом.

## Как запустить

Скрипты находятся в `scripts/`. Для обозначенных в таблице групп `inventory` используйте `playtest-screen-inventory.py`; перечень параметров показывает `--help`. Порядок подготовки Python и Node описан в [руководстве по плейтесту](playtest.md).

Во время терминального сценария сборка должна оставаться неизменной. Проверяйте видимый кадр и код завершения процесса; наличие старого файла отчёта не означает, что новый прогон завершился успешно.

Локальные фикстуры не проверяют облачную авторизацию, реальные ограничения аккаунта или системное хранилище ключей. Нативные терминалы Windows и Linux требуют отдельных проходов.
