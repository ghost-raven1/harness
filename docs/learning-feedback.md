# Обратная связь и отзыв знаний

Отзыв «Нашёл ошибку» для задачи делает её прежние положительные подтверждения непригодными для обучения. Ожидающие задания на основе этих подтверждений останавливаются. Модель получает текст опровержения как контекст, но не может сослаться на него как на доказательство успешного результата.

Если опубликованный урок ссылался на опровергнутое подтверждение, Harness отзывает урок и откатывает активный выпуск до ближайшего предка без него. Поэтому более поздние выпуски, включающие этот урок, тоже перестают применяться к новым задачам. Уже начатая задача сохраняет свою версию опыта, включая её содержимое.

Общая отрицательная оценка не отменяет фактические результаты инструментов и уроки, опирающиеся только на них. Для отзыва конкретного такого урока нужно указать `candidateId` в `learning feedback` либо выполнить `learning rollback`.

Повторная отправка полностью одинакового отзыва считается повторной доставкой: она не создаёт новое задание и не возвращает силу отозванному подтверждению. После исправления дайте новый положительный отзыв с описанием повторной проверки.

Отозванный кандидат не возвращается в оценку после паузы или перезапуска. Незавершённая оценка может продолжиться только для кандидата, который всё ещё ожидает проверки.
