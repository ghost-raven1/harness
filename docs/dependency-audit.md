# Проверка зависимостей

Проверка выполнена 12 сентября 2026 на Node.js 24.21.0. `npm audit` после обновления не сообщает критических, высоких или умеренных проблем. Остаются пять записей low: четыре адаптера и их общая зависимость `@ai-sdk/provider-utils`.

- Node.js 24.21.0; версия установщиков, CLI и проверки дерева берётся из `.nvmrc`.
- NestJS 11.2.3, Vitest 4.1.11, Vite 7.3.6, типы Node 24.13.4.
- ajv 8.20.0, minimatch 9.0.9, diff 8.0.4.
- Версии фиксированы `package-lock.json`; несовместимые Node engines блокируют установку.

Оставшийся advisory: [Uncontrolled Resource Consumption в provider-utils](https://github.com/advisories/GHSA-866g-f22w-33x8). Исправленная ветка меняет контракт AI SDK; принудительная замена транзитивной зависимости на другую major-версию не выполнялась. Перед библиотечным парсером установлен лимит сырых ответов 8 МиБ. Проверка отправляет поток без разделителей SSE и подтверждает отказ и отмену чтения при превышении. Это сдерживает размер буфера в нашем транспорте, но не устраняет отметку уязвимости самого пакета.

Повторить аудит: `npm audit`. Unit/integration: `npm run check`. Нативная библиотека хранилища ключей optional: отказ загрузки не препятствует вводу ключа на время окна; на macOS дополнительно проверены операции с временной записью.
