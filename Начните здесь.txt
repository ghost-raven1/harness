HARNESS

1. Откройте файл для своей системы:
   macOS: «Запустить Harness.command» — двойной щелчок.
   Windows: «Запустить Harness.cmd» — двойной щелчок.
   Linux: start.sh — запустить в терминале через файловый менеджер.
   Если менеджер открывает текст: откройте терминал в этой папке и введите ./start.sh

2. При первом запуске дождитесь подготовки. Нужен интернет.
   Приложение само загрузит нужный Node.js и библиотеки в свою папку.
   Системную установку Node.js оно не меняет.

3. Выберите папку, с которой хотите работать, и провайдера модели.
   Ключ доступа вставьте в скрытое поле. Настраивать переменные вручную не нужно.
   Если ключа нет — в списке провайдеров есть пункт с подсказками.

4. Выберите «Новая задача» и напишите, что нужно сделать.
   Например: «Изучи файлы в папке и объясни, что здесь находится».

Управление: стрелки — выбор, Enter — подтвердить, Esc — назад.
Во время задачи: Esc — в меню, Ctrl+C — остановить задачу.
После ответа можно продолжить разговор или сохранить ответ в файл.
История находится в «Моих задачах». Для следующего запуска снова откройте тот же файл.

Ключ действует до закрытия окна или, по вашему выбору, сохраняется в хранилище ОС.
Перед записью файла показывается сравнение строк. После задачи файл можно восстановить.
Поиск старых задач, недавние проекты и расходы API доступны через меню.
Облачные запросы могут быть платными. Самообучение тоже использует API;
его можно приостановить в настройках. API-ключ не вставляйте в текст задачи.

Если система блокирует запуск файла, используйте штатный пункт «Открыть»
или обратитесь к администратору компьютера. Не отключайте защиту системы.

Подробная инструкция: docs/getting-started.md
Проверены macOS и Linux. Нативная проверка Windows пока не выполнена.
